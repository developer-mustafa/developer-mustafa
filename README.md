## 🧠 Engineering Principles

I believe effective software engineering is more than writing code. It means making thoughtful decisions that support the product throughout its lifecycle.

- **Maintainability:** Keep code modular, readable, and easy to extend.
- **Reliability:** Validate assumptions and test critical workflows.
- **Security:** Protect credentials, validate inputs, and enforce authorization.
- **Performance:** Identify bottlenecks and optimize where it matters.
- **Minimal-risk changes:** Preserve existing behavior when improving established systems.
- **Product thinking:** Connect technical decisions to real user needs.
- **Continuous learning:** Improve through experimentation, feedback, and practical projects.
